# GIGACRED BH — apresentação institucional

Site estático, responsivo e sem dependências de compilação. Os arquivos `index.html`, `styles.css`, `app.js` e a pasta `assets` contêm toda a aplicação.

## Executar localmente

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

Abra http://127.0.0.1:4173.

## Conteúdo e referências

Identidade preta/amarela, logo, publicações, modalidades e WhatsApp (31) 98116-8246 conferidos no perfil https://www.instagram.com/gigacredbh/ em 17/11/2026. Fotografias ilustrativas de arquitetura: Unsplash. As imagens do Instagram estão hospedadas localmente para evitar dependência de URLs temporárias.

O site é uma proposta para apresentação à empresa. Não contém depoimentos, parceiros bancários, estatísticas, taxas ou promessas de aprovação inventados. Razão social, CNPJ, endereço e condições comerciais precisam ser validados pela empresa antes do uso comercial definitivo.

O planejador realiza apenas a divisão aritmética entre entrada e valor restante. Não calcula parcelas, juros ou elegibilidade. Nenhum dado é salvo. Botões de WhatsApp abrem uma mensagem que o visitante revisa e envia por conta própria.

Fontes DM Sans e Manrope carregadas pelo Google Fonts, com fallback local. Navegação, ferramentas e imagens funcionam sem serviços de backend. Para hospedar, publique o conteúdo desta pasta em um serviço de hospedagem estática. A versão Nuvemshop utiliza um rascunho com um bloco de código personalizado.
